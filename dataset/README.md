# Dataset Information

Dataset Name:
Digital Detox Dataset

Format:
CSV

Description:
This dataset contains information related to digital wellness including:

- Age
- Gender
- Daily Screen Time
- Sleep Hours
- Stress Level
- Social Media Usage
- Gaming Hours
- Work/Study Hours
- Notifications
- App Opens
- Addiction Level
- Device Usage
- Productivity

Purpose:
To analyze digital habits and generate insights using Data Science techniques.
