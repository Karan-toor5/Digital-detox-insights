## 📌 Project Overview

**Digital Detox: Intelligent Insights for Digital Well-being** is an interactive
data analysis and visualization dashboard developed using **Python and Streamlit**.

The project analyzes digital wellness and screen-time behavior using a structured
dataset containing information about users' screen time, social media usage,
gaming activities, work/study hours, sleep, notifications, app usage, stress,
academic impact, and addiction levels.

The main purpose of the project is to transform raw digital wellness data into
meaningful visual insights that can help users understand digital usage patterns
and their relationship with sleep, stress, productivity, and digital addiction.

> **Note:** This project focuses on data analysis, exploratory data analysis (EDA),
> filtering, statistical summaries, and visualization. No machine learning model
> is used.

## 🎯 Objectives

The major objectives of this project are:

- Analyze digital screen-time behavior.
- Study social media and gaming usage patterns.
- Analyze the relationship between screen time and sleep hours.
- Examine stress and academic/work-study impact.
- Analyze digital addiction levels and addiction status.
- Provide interactive filtering based on user-selected criteria.
- Generate meaningful charts and visualizations.
- Provide statistical and descriptive summaries of the dataset.
- Present digital wellness patterns through an easy-to-use dashboard.
- Help users understand their digital behavior through data-driven insights.

## ✨ Key Features

### 📊 Dataset Overview

The dashboard provides an overview of the loaded dataset, including:

- Total number of records
- Total number of columns
- Missing values
- Memory usage
- Dataset structure

### 🔍 Data Exploration

The dashboard provides different tabs for exploring the dataset:

- Column Information
- Missing Values
- Sample Data
- Statistical Summary
- Categorical Data

### 🎯 Interactive Filters

Users can filter the dataset using multiple criteria such as:

- Gender
- Addiction Level
- Stress Level
- Addiction Status
- Age
- Sleep Hours

The selected filters are applied to the analysis and visualizations.

### 📈 Visualization and Insights

The dashboard provides interactive visualizations for analyzing:

- Average Daily Screen Time
- Screen Time across Age Groups
- Screen Time by Gender
- Social Media Usage
- Gaming Usage
- Work/Study Hours
- Sleep Hours
- Stress Levels
- Addiction Levels
- Academic Work Impact
- Digital Wellness Patterns
- Relationships between numerical variables

### 📋 Statistical Analysis

The application provides statistical summaries of numerical
and categorical data to understand the distribution and characteristics
of the dataset.

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Karan-toor5/Digital-detox-insights.git
   cd Digital-detox-insights
   ```

2. Install Required Dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. ▶️ Running the Project:
   ```bash
   streamlit run digiapp.py
   ```

   After successful execution, Streamlit will provide a local URL, normally:

   ```text
   http://localhost:8501
   ```

   Open this URL in a web browser to access the dashboard.
